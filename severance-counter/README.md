# 월급 해금 (안드로이드)

이번 달 번 돈이 초당 쌓이는 걸 잠금화면 알림으로 보여주고, 금액대별로 아이템이 해금되는 안드로이드 앱입니다.
연봉만 입력하면 상시표시 알림(ongoing notification)과 홈 화면 위젯에 실시간으로 반영됩니다.

## 먼저 알아둘 것 — 안드로이드는 "잠금화면 위젯"이 없습니다

iOS 16+와 달리 안드로이드는 5.0 이후 잠금화면 전용 위젯을 공식적으로 지원하지 않습니다.
그래서 이 앱은 **상시표시 알림(ongoing notification)**을 잠금화면에 노출시키는 방식으로 구현했습니다.
- 알림은 기기 설정에서 "잠금화면에 모든 알림 내용 표시"를 켜야 금액까지 잠금화면에서 바로 보입니다
  (설정 > 알림 > 고급 설정, 또는 기기 제조사마다 위치가 조금씩 다름)
- 추가로 홈 화면 위젯도 같이 넣어뒀습니다(집에 있을 때 홈 화면에서도 바로 확인 가능)

## 여는 법 (Android Studio 필요)

1. Android Studio(최신 버전 권장)로 이 폴더(`salary-counter/`)를 **Open** → 그래들 동기화가 끝날 때까지 대기
2. 실기기 또는 에뮬레이터(API 26 이상)에서 Run
3. 앱 실행 후 연봉(만원) 입력 → "카운팅 시작"
   - Android 13(API 33) 이상이면 알림 권한을 한 번 물어봅니다 → 허용
4. 화면을 잠그고 알림창을 내려서 "이번 달 번 돈" 알림 확인
5. 홈 화면을 길게 눌러 위젯 추가 → "월급 해금" 위젯 배치

## 구조

```
app/src/main/java/com/example/severancecounter/
  MainActivity.kt              연봉 입력 화면
  SeveranceForegroundService.kt   1초마다 알림/위젯을 갱신하는 포그라운드 서비스
  SeveranceWidgetProvider.kt      홈 화면 위젯
  SeveranceTiers.kt                해금 아이템 71종 (데모 웹 버전과 동일한 리스트)
  SeveranceCalculator.kt          연봉 → 초당/월간 금액 계산
  SeverancePrefs.kt               연봉, 실행 상태, 프라이버시 모드 저장
  BootReceiver.kt              기기 재부팅 후 자동 재시작
```

## 알려진 제약 / 다음에 손볼 만한 것

- **배터리**: 1초마다 알림을 갱신합니다. 포그라운드 서비스라 시스템이 죽이진 않지만, 배터리가 아깝다면
  `SeveranceForegroundService.TICK_INTERVAL_MS` 값을 3000~5000(3~5초)으로 늘리는 게 안전합니다.
- **알림 갱신 제한**: 일부 제조사(특히 삼성 One UI)는 너무 잦은 알림 갱신을 배터리 최적화 대상으로 묶을 수 있습니다.
  설정에서 이 앱을 "배터리 사용 제한 없음"으로 지정해두는 걸 권장합니다.
- **프라이버시 모드**: 알림 하단 "가리기/보기" 버튼으로 토글됩니다. 기본값은 가림(hidden)입니다.
- **아이콘**: 지금은 임시 벡터 아이콘입니다. 실제 배포 전에 제대로 된 런처 아이콘으로 교체하는 걸 추천합니다.
- **Google Play 배포 시**: `FOREGROUND_SERVICE_SPECIAL_USE` 권한은 콘솔에 사용 목적을 소명해야 합니다.
